# Como pedir — automacao-direct

## Primeira vez (setup, ~5 minutos)

Cole no Claude Code:

```
Quero configurar a skill automacao-direct pra fazer automação de comentário → DM
no meu Instagram. Me guia no setup do zero, ainda não tenho conta na Zernio.
```

O Claude te guia: conta grátis na Zernio → conectar seu Instagram (login oficial da Meta) → colar a chave de API. Uma vez só; a skill publicar-agendar-posts usa a mesma config.

## Criar uma automação

```
Cria uma automação: quem comentar GUIA em qualquer post meu recebe no direct
o link https://meusite.com/guia com o botão "Baixar o guia".
Quero a trava de seguidor ativada.
```

```
Quem responder meu story com AULA recebe o link da aula no direct.
```

## Acompanhar

```
Como tá a automação GUIA? Quantas pessoas comentaram e quantas clicaram?
```

```
Me mostra o log da automação: quem comentou e o que aconteceu com cada um.
```

## Gerenciar

```
Pausa a automação GUIA.
```

```
Troca o link da automação GUIA pra https://meusite.com/novo-guia
```

## Dicas

- Palavra-chave boa: UMA palavra, memorável, fácil de digitar (GUIA, LISTA, QUERO, AULA).
- O match é por palavra isolada: "GUIA" não dispara em "guiado". Pode usar palavra natural sem medo.
- Uma automação vale pra TODOS os seus posts: cria uma vez, usa em todo post com o mesmo CTA.
- No post, o CTA vai na legenda e/ou no primeiro comentário: "Comenta GUIA que eu te mando 👇 (primeira vez aqui? olha nas solicitações de mensagem)".
- Trava de seguidor = mais seguidores, um toque a mais de atrito. Sem trava = mais entregas. Teste os dois.
