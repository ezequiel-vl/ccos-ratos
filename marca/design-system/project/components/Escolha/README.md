# Escolha
Par de pílulas pra responder uma pergunta com uma das opções.

Em repouso: contorno `line-2`, texto `mute`. Escolhida (`aria-pressed="true"`): fundo `cta`, texto `on-cta`. 44px de altura, gap `space-2`.

**O consumidor fornece** o `role="group"` com `aria-label`, os botões com `aria-pressed`, e a lógica que marca um e desmarca o outro.

**Rótulos**: o que aconteceu, na voz do dono, curto. "Apareceu / Não apareceu", "Abriu / Não abriu", "Termina / É @gmail ou parecido".

**Use** no teste das 4 portas e em diagnóstico de sim ou não. **Não use** pra mais de 3 opções.
