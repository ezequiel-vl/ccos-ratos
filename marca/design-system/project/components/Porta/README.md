# Porta
Card de 300px com etiqueta do andar, nome e uma linha sobre onde o cliente procura.

Superfície `surface`, borda `line`, raio `radius-card`, padding `space-5`. A etiqueta (`rotulo`, em `faint`) diz o andar do método: Ponto, Movimento ou Atendimento. Título em `card-titulo`, texto em `body-sm`/`mute`.

**O consumidor fornece** o andar, o nome da porta e uma frase concreta do que muda pro cliente.

**Use** na esteira: duas fileiras correndo em sentidos opostos conforme a página rola. **Não use** como grade fixa de cards iguais com ícone, que é cara de template.
