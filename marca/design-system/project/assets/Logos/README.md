# Logos

- **ezeos-horizontal-branco.png**: logotipo eze.OS para fundo escuro. 1597 × 400 px, fundo transparente, letras `#ffffff` e ponto `#48a0c7` (`sinal`). Use no site, no carrossel e no slide escuros.
- **ezeos-horizontal-preto.png**: logotipo eze.OS para fundo claro. 1597 × 400 px, fundo transparente, letras `#000000` e ponto `#48a0c7` (`sinal`). Use em proposta, documento e PDF.
- **ezeos-simbolo.svg**: o símbolo, um círculo único em `#48a0c7` (tinta fixa, não herda cor) num canvas de 256 × 256. Use em favicon, foto de perfil e app icon sobre quadrado `bg`.
